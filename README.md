# IoT Patient Health Monitoring System
B.Tech ECE - Real-time patient health on cloud using IoT

## Features
- Heartbeat Monitoring (Pulse Sensor)
- Temperature (LM35)
- IoT Cloud ThingSpeak Dashboard
- Emergency Buzzer Alert
- OLED Display
- NodeMCU ESP8266 WiFi

## Working
Sensors -> NodeMCU reads data -> Display on OLED -> Send to Cloud -> Alert if abnormal
